About Me

NGUYEN Do Duc Anh is a PhD student at IMT Atlantique in France, working in the SOTERN team of IRISA. He received his Master's degree in Information Security from the University of Limoges, France.

His current research focuses on developing an automated attack response system, with a particular emphasis on using Intent-Based Networking and Microservices as key components of security configuration automation.

Projects

  • Opportunistic Synchronization Mechanism, 2025
    Implemented a fast-reaction mechanism leveraging existing traffic to deliver information between security functions (microservices) across both emulation (GNS3) and simulation (OMNET++) environments.

  • Malware Propagation Testbed, 2024
    Built and configured an emulation testbed to dynamically analyze behavior and measure the real-world propagation speeds of WannaCry and NotPetya malware.

  • Policy Conflict Detection and Resolution for I2NSF Framework, 2023
    Implemented a new conflict policy detection and resolution mechanism for the I2NSF framework proposed by the IETF. This user-level mechanism provides meaningful feedback for conflict resolution.

  • Worker Controller & Congestion Management, 2020
    Handled over 100 million user requests per day. Defined new commands using TCP and built GET/POST protocols using Apache Thrift and Jetty Servlet. Managed resource evaluation, implemented caching, and troubleshot server congestion (CPU/RAM/Traffic), successfully eliminating traffic congestion errors during rush hours.

  • Server for Searching Data, 2019
    Built an application for searching data using ElasticSearch API. Optimized the searching capabilities and used network protocols (HTTPS, TCP, UDP) with NoSQL databases, improving processing speed 3 times faster.

  • Database Accessing Tool, 2018
    Built a permissions tool allowing other departments to directly interact with the database, significantly reducing permission wait times.

  • Monitoring Tool, 2018
    Built a tool that crawls resource consumption from various servers to detect incidents (slow/overload/error/dead) and notify admins via mobile applications, helping avoid serious system failures through early detection.

Course Projects

  • Networking Infrastructure Building, May 2021
    Configured iptables rules of routers to pass two types of connections: Internet connection through the normal route and VLAN connections between two private networks via an IPSec Tunnel.

  • Shared Secret Key Simulation, May 2021
    Implemented the QC-MDPC Key Exchange protocol (similar concept to Diffie-Hellman). Utilized the BitFlipping algorithm to recover the shared key after the Challenge-Answer step of two communicators.

  • Intrusion Detection System, March–May 2021
    Trained a Deep Learning Network model to automatically detect networking attacks such as DoS, Probing, etc. Built a program to capture packets and convert them into dataset format to simulate real-time detection.
    Demo video: github.com/anhndd/intrusion_detection_system

  • Packet Translation, April 2021
    Built a packet translation system to allow connections (using simple protocols like TCP or UDP) between IPv4 and IPv6 devices to behave as normal connections.

  • Private Networking Firewall, January 2021
    Managed internet requests from host networks using a Firewall set up on a virtual router. All requests are redirected to a login page and require authentication before internet access is authorized.
  • Encrypting & Decrypting Application
    Led a team of 3 members. Built an application providing encryption and decryption functions applying algorithms of RSA and DES.

  • Chatting Application
    Led a team of 4 members. Designed the UI and implemented features for an Android application using Java.
